# DiskGuard 桌面宠物（默认西高地 + 可扩展自定义角色包）设计文档

- **日期**：2026-11-28
- **状态**：已确认并进入实现

---

## 1. 设计目标与克制原则

将「会呼吸的监控桌宠」收敛进 DiskGuard 现有的单一无边框悬浮窗（`FloatingHUDPanel`），在不新增主窗口 Tab、不增加第二个悬浮窗的前提下，提供治愈、轻量且可持续扩展的桌面系统状态陪伴：

1. **默认形态即桌宠**：桌面平时只呈现一只带柔和底影、自然呼吸的小西高地白梗（无边框、无底色卡片、不遮挡视线）。
2. **数据按需浮现**：鼠标悬停时才在角色头顶浮出一行半透明状态胶囊（内存 / CPU / VPN / 温度）与极简切换按钮；平时不抢占注意力。
3. **统一角色包引擎**：内置西高地与未来导入的自定义角色（如家人的 Q 版卡通形象）使用同一套 `PetPack` 目录格式、本地 `Vision` 抠图管线与动效引擎；自定义角色只需 1 张主图即可生效，也支持补充多状态表情图。
4. **纯本地与低功耗**：所有抠图与状态判定 100% 本地完成，不发起任何外网请求；呼吸/微动画使用 GPU 合成层 `CoreAnimation`（`CABasicAnimation`），保证稳态主线程空闲于 `mach_msg2_trap`。

## 2. 悬浮窗三态收敛（`FloatingHUDMode`）

将原有「展开 / 迷你胶囊」二态升级为三态：

- `.pet`（**桌宠**，默认）：仅展示呼吸角色；顶部预留透明安全区，悬停胶囊与对话气泡原地淡入，不触发窗口尺寸重算或角色位置抖动。
  - **单击**：摸摸头，触发 `happy` 反应、爱心贴纸与短时可爱状态气泡（约 2.8 秒后自动消失）。
  - **双击**：还原 DiskGuard 主窗口。
  - **拖拽**：全窗背景可拖拽，自动记忆并恢复屏幕坐标（夹紧在可见工作区内）。
  - **右键菜单**：切换三态（桌宠 / 迷你胶囊 / 完整仪表盘）、调整尺寸（小 76pt / 中 96pt / 大 120pt）、切换宠物角色、「导入 / 管理自定义桌宠…」、常驻与隐藏。
- `.pill`（**迷你胶囊**）：保留原有单行紧凑指标胶囊。
- `.expanded`（**完整仪表盘**）：保留原有双圆环 + 网速 + 磁盘容量悬浮面板。

主窗口不新增 Tab，仅在右上角设置齿轮菜单与菜单栏弹出面板中提供「悬浮窗形态」与「管理桌宠形象…」。

## 3. 五状态映射与防抖（`PetMood`）

直接消费 `SystemMonitorSampler` 采样数据，按以下优先级判定：

1. `happy`（开心）：单击摸摸头后 4 秒，或磁盘清理成功完成后 6 秒。
2. `stressed`（紧张晕乎）：内存压力 `.critical`，或 `.warning` 且占用率 `>= 85%`，或可用磁盘空间 `< 15 GB`（`> 0`）。
3. `busy`（忙碌冒汗）：CPU 总使用率 `>= 65%`，或设备温度 `.serious` / `.critical`。
4. `sleepy`（犯困打盹）：深夜 `23:30–05:30` 且 CPU `< 30%`，或电池电量 `< 20%` 且未插电。
5. `idle`（悠闲乖坐）：其余正常工况。

通过 `PetMoodStabilizer`（默认最小保持 5 秒）防止临界指标频繁抖动，同时对 `happy` 与 `stressed` 允许立即响应。

## 4. 角色包与本地抠图管线

- **内置角色**：`Sources/DiskGuard/Resources/Pets/westie/`（`manifest.json` + 5 张 `512×512` 透明底 PNG），打包至 `DiskGuard.app/Contents/Resources/Pets/westie/`（同时兼容 `Bundle.module`）。
- **自定义角色目录**：`~/Library/Application Support/DiskGuard/Pets/<id>/`。
- **单图兼容与降级**：`PetPack.imageURL(for:)` 优先返回对应状态的专属贴图，缺失时自动回退至 `idle.png`，并由 `DesktopPetView` 根据当前 `PetMood` 叠加轻量状态贴纸（爱心、汗滴、晕星、Zzz）与对应的呼吸/摇晃节奏。
- **本地抠图**：利用 macOS 14 原生 `Vision`（`VNGenerateForegroundInstanceMaskRequest`）+ `CoreImage` 遮罩合成，全本地去背并按底部对齐规范输出透明 PNG。
